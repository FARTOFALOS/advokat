## Каноническая логика обновления

После нового события:

1. сначала запись в корневой `ЖУРНАЛ.md`;
2. затем обновить [01](01_ГДЕ_МЫ_СЕЙЧАС.md);
3. перевести нужный пункт в [13](13_КАРТА_ФАКТОВ_И_НЕИЗВЕСТНОГО.md) из «НЕИЗВЕСТНО» в «ФАКТ» только с источником;
4. обновить событийный runbook, если ближайшее событие изменилось;
5. [02](02_СТРАТЕГИЯ.md) менять только если новый факт действительно меняет архитектуру, а не просто маршрут.

Так следующий агент видит разницу между:
- **миссия/критерии**;
- **текущий маршрут**;
- **фактическое состояние**;
- **сценарий события**.

## Смысловая позиция в одной строке

> Клиент не отрицает пользование картой и лимитом; он оспаривает доказанность конкретных договорных условий, отдельных составляющих долга и наступление срока всей суммы, используя только добросовестные процессуальные механизмы, чтобы сохранить законно защищённое время до выполнимого режима платежей и не допустить неприемлемого риска автомобилю.

## Важное ограничение о публичности

На момент проверки 05.10.2026 репозиторий имеет статус **public**.  
Внутренние master-strategy, критерии переговоров и CAR-протокол **не предназначены для направления суду или банку**.

Сам факт публичности означает, что нельзя считать внутреннюю стратегию конфиденциальной только потому, что файл помечен «для себя». Если конфиденциальность нужна, видимость репозитория должна быть изменена владельцем отдельно.

## Что является архивом

V1/V2/V3/V3.1, ROADMAP_V3.html, P01–P07, старые шпаргалки и проекты Д1–Д7 сохраняются как:
- происхождение аргументов;
- история исправлений;
- копии уже подготовленных/поданных текстов.

Они **не имеют приоритета** над 01 → 02 → 13 → событийным runbook → CAR protocol.
