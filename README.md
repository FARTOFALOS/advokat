## Правила ведения

1. Любое новое событие — запись в [`ЖУРНАЛ.md`](ЖУРНАЛ.md) с датой и источником (суд, квитанция, клиент, проверка).
2. Обновить [`01_ГДЕ_МЫ_СЕЙЧАС.md`](ABANK/00_ТЕКУЩЕЕ/01_ГДЕ_МЫ_СЕЙЧАС.md); при смене развилки — стратегию и веер.
3. Поданный документ — в `ABANK/00_ТЕКУЩЕЕ/подано/ГГГГ-ММ-ДД_Название/` с текстом, вложениями и статусом.
4. Документ суда — в `ABANK/копии ответов…/` (имя `NNNN_ГГГГ-ММ-ДД_Название`).
5. Подача в ЕСИТС — **два шага**: «Підписати та відправити сторонам», затем **«Підписати та відправити до суду»**. Проверять, что статус стал «Доставлено до суду» или «Зареєстровано».
6. Ключ `.pfx`, архивы `.zip` и временные файлы не загружать: их отсекает [`.gitignore`](.gitignore).
